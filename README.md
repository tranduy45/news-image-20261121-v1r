# The World in One Day — Saturday 21 November 2026

A one-page newspaper front page summarising 21 November 2026's world
news in a single 1024×1024 image, for the make.fun bounty
`news-image-20261121`.

## Contents

- 3 hero stories: Russia's overnight strikes on Ukraine (Kryvyi Rih),
  COP31 running into overtime in Antalya, and KL Rahul's hundred for
  India at Wellington.
- 12 more stories (Washington, Tehran, Hodeidah, Brussels, Copenhagen,
  Warsaw, Dhaka, Ulaanbaatar, Doha, Gaza, Naypyidaw) with a small flat
  illustration each.
- A world map marking stories 1–15, an ALSO list (stories 16–36), a
  number strip, a timeline strip, and a DATE CHECK strip listing items
  first reported on 19–20 November that are deliberately NOT presented
  as 21 November news.
- Region totals: Europe 9, Asia-Pacific 13, Americas 5, Oceania 3,
  Mideast 4, Africa 2 (36 stories in all).

## Verification

Every fact was checked against wire reports (Reuters, AP, AFP, BBC,
Dawn, The Hindu, NST, Manila Times, UN News) read on 21 November 2026.
All illustrations are original flat drawings made in code, not
photographs.

## Run

```
python3 main.py          # writes entry.png next to main.py
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program renders the same bytes every run (no clocks, no randomness).
